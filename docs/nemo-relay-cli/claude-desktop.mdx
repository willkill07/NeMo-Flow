Enroll Claude Desktop:

```bash
nemo-relay install claude-desktop
```

<Warning>
Claude Desktop adapters are implemented on macOS, Windows, Ubuntu, and Debian,
but each platform still requires its integrated live-application release gate.
Treat explicit Desktop enrollment as preview until the support matrix marks
that platform supported.
</Warning>

On macOS and Windows, the installer changes current-user TLS trust; Linux uses
an agent-scoped CA bundle instead. It patches the authenticated HTTPS proxy and
CA settings used by the Desktop Code tab, retains native OAuth, and installs
fail-closed lifecycle hooks. Claude Code and Claude Desktop have separate
ownership records over their shared Claude configuration, but provider traffic
uses one active shared Claude credential and upstream route.
The shared plugin keeps the canonical Claude Code hook schema and uses the
Desktop enrollment credential whenever Desktop is the only Claude owner.

After enrollment, open a protected Code session through the retained deep-link
command:

```bash
nemo-relay claude-desktop --folder /path/to/project
```

Before opening Claude, the command verifies the service executable, health,
generation, configuration fingerprint, trust fingerprint, effective settings,
and hooks. It refuses to open a session if protection is incomplete.

The integration covers local Claude Desktop Code activity that uses the
enrolled user configuration. Claude Chat, Cowork, web traffic, and cloud
execution remain outside scope.

Diagnose the installation with:

```bash
nemo-relay doctor claude-desktop
```

Uninstall with:

```bash
nemo-relay uninstall claude-desktop
```

If Claude Code remains enrolled, uninstall preserves shared Claude fields that
it still owns. The current-user CA and service remain until the final agent
enrollment is removed.
