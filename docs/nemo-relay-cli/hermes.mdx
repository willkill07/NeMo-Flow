Enroll Hermes, then start its local modes normally:

```bash
nemo-relay install hermes
hermes
```

Relay patches the enrolled `$HERMES_HOME` environment with authenticated proxy
and CA values used by the local CLI, gateway, cron, API-server, ACP, and
desktop-backed local modes. It installs trusted lifecycle hooks and retains
exact previous values for uninstall. It does not install a Relay MCP server.
The generated Hermes CA bundle retains the original Requests/OpenSSL bundle
and distinct `NODE_EXTRA_CA_CERTS` input. When none was configured, Relay
exports the platform native roots before appending its constrained root; CA
rotation rebuilds from those original trust inputs.

## Native Providers

Relay manages Hermes traffic to:

- `api.anthropic.com`
- `api.openai.com`
- `chatgpt.com`

Managed calls use the matching provider codec, request and execution
interceptors, streaming finalizer, and the Hermes enrollment's corporate proxy
route.

## Unknown Providers

Unsupported public provider hosts reached with `CONNECT` on port 443 are
tunneled without TLS interception or certificate generation. Other ports and
private or reserved destinations are rejected. Hermes lifecycle events for
the tunneled providers are clearly labeled:

```text
managed_inference=false
observability_mode=hook_only_degraded
```

Request and execution interceptors cannot apply to an opaque unknown-provider
stream. This is the sole intentional exception to managed-inference fail-closed
behavior. Remote Hermes backends are also outside local coverage.

## Proxy Conflicts

Hermes can inherit higher-precedence ambient `HTTP_PROXY`, `HTTPS_PROXY`, CA,
or bypass settings. Run:

```bash
nemo-relay doctor hermes
```

Doctor checks the enrolled home, environment patch, ambient conflicts, hooks,
service, trust, and provider mode inferred from the configured base URL. It
reports `managed_proxy` only after enrollment and proxy-environment verification
for a credential-free HTTPS/443 URL on a known native host and audited path.
HTTP, alternate ports, URL credentials, unsupported paths, and unknown
providers report `hook_only_degraded`. Doctor does not contact or identify the
provider.

Remove only Relay-owned Hermes values with:

```bash
nemo-relay uninstall hermes
```
