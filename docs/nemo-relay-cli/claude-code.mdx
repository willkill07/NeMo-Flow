Enroll Claude Code, then launch `claude` normally:

```bash
nemo-relay install claude-code
claude
```

Relay installs authenticated HTTPS proxy and CA settings plus fail-closed
lifecycle hooks in the user's Claude configuration. It preserves native
Anthropic OAuth and the exact previous values required for uninstall.

Claude Code connects to `api.anthropic.com` through the discovered per-user
listener. Relay verifies the Claude credential, `CONNECT` authority, TLS SNI,
and HTTP host before minting an exact-host leaf. Supported Anthropic Messages
HTTP/SSE calls use Relay's managed codec and middleware pipeline.

The integration uses system and user Relay configuration only. The removed
transparent wrapper and project `.nemo-relay` configuration are not consulted.
There is no Relay MCP entry.

Run:

```bash
nemo-relay doctor claude-code
```

Doctor verifies the service, trust, Claude settings, hook commands, generation,
and provider route. A stopped or mismatched service causes managed requests and
installed hook delivery to fail closed.

Claude Chat, Cowork, web traffic, and remote execution are outside local
Claude Code coverage. For the Claude Desktop Code tab, refer to
[Claude Desktop](/nemo-relay-cli/claude-desktop).

Remove only the Claude Code enrollment with:

```bash
nemo-relay uninstall claude-code
```

If Claude Desktop remains enrolled, shared Claude fields still owned by that
enrollment are preserved. The retained shared plugin switches hook health and
delivery to the Desktop credential, so lifecycle hooks remain fail closed
without a direct Claude Code enrollment.
